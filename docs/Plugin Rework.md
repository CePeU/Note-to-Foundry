# NoteToFoundry Plugin

The current source uses the new plugin ID `NoteToFoundry` and requires Obsidian 1.13.4 or later. Follow the [installation and migration guide](docs/migration-NoteToFoundry.md) before enabling this build. See [setup and profile sharing](docs/rework-usage.md), [adding a destination](docs/destination-development.md), and the [bug-fix validation and handoff](Bugreports/STATUS.md). Live Obsidian/Foundry checks are still pending; the historical screenshots and setup details below describe the older interface and installation.

Adjusts and exports the natively as HTML rendered Markdown from Obsidian to Foundry VTT.  
An [Obsidian](https://obsidian.md) plugin to copy notes as HTML to the clipboard, export as file and/or upload as journal to Foundry VTT. Also allows for relinking of notes.
